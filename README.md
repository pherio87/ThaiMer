# Thaimer

Thaimer è un timer a intervalli per allenamenti di Muay Thai, Boxe, HIIT, Tabata e circuiti. Permette di creare allenamenti personalizzati o scegliere tra modelli, con indicazioni sonore e vocali durante le fasi.

L'app è utilizzabile dal browser, installabile come PWA e disponibile anche come app Android. Supporta l'uso offline; su Android offre controlli tramite notifica e può continuare l'allenamento in background.

Thaimer è realizzata con HTML, CSS e JavaScript, senza framework o processo di build per la versione web. L'app Android è basata su Capacitor.
